Material Web

@material/web is a library of web components that helps build beautiful and accessible web applications.

Note: MWC is in maintenance mode pending new maintainers.

What's new in 3.0

Version 3.0 adds the Material 3 Expressive components, named md-gb-*. These pages exist only in 3.0:

  • App bar
  • Badge
  • Button group
  • Card
  • Carousel
  • Date picker
  • FAB menu
  • Loading indicator
  • Navigation bar
  • Navigation drawer
  • Navigation rail
  • Pull to refresh
  • Scaffold
  • Search
  • Segmented button
  • Sheets
  • Snackbar
  • Split button
  • Time picker
  • Toolbar
  • Tooltip

Moving from 2.5.0? Read the migration guide. For the spec status of each component, see the compliance page.
