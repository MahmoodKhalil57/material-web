Debugging

The shared plumbing of the components (motion waits, overflow measure passes, and scroll steps) can record performance marks.

View as Markdown

Performance track

Link to “Performance track” #

The shared plumbing of the components (motion waits, overflow measure passes, and scroll steps) can record performance marks. They show up in the Chrome DevTools Performance panel as a custom track named md-gb, in the group Material. The marks are off by default.

Turn them on

Link to “Turn them on” #

The flag is read once, on first use, so set it before you interact with the components. Use any one of these:

  • Add ?md-gb-perf to the page address and load it.
  • Set the flag in the console, then reload. Any value turns the marks on, even 0. Remove the key to turn them off (the first sample below).
  • Set globalThis.MD_GB_DEBUG_PERF = true before any component runs (the second sample below).

Install Material Web 3.0

Your browser did not offer to install the docs as an app. Install them from the browser instead:

  • Chrome and Edge: open the browser menu and choose Install Material Web 3.0 (Chrome: Cast, save and share, Install page as app), or use the install icon in the address bar.
  • Safari on Mac: choose File, then Add to Dock.
  • Safari on iPhone and iPad: tap Share, then Add to Home Screen.
  • Firefox: Firefox on Android has Install in its menu. Firefox on desktop cannot install web apps; bookmark this page instead.
