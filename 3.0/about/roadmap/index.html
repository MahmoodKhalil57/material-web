Roadmap

This roadmap describes current, future, and past goals for Material Web Components.

View as Markdown

Current

Link to “Current” #

Version 3.0 (labs/gb) is the M3 Expressive implementation of MWC. It adds Expressive components (such as the button group, split button, FAB menu, carousel, loading indicator, and toolbar), dynamic color, the Expressive shape, type, and motion systems, WAI-ARIA 1.3 conformance, and Web Platform Baseline fallbacks. Version 2.5.0 remains in maintenance mode.

Future

Link to “Future” #

Note: No future work is planned while MWC is in maintenance mode. These roadmap items represent what used to be planned.

New components

Link to “New components” #

Version 3.0 builds every component in the list 2.5.0 planned except these:

  • Autocomplete
  • Banner
  • Data table

The badge, bottom sheet, card, date and time pickers, navigation bar, drawer and rail, search, segmented button, snackbar, tooltip and top app bar are in labs/gb. The toolbar replaces the bottom app bar in M3 Expressive.

Expand Material Design tokens

Link to “Expand Material Design tokens” #

Version 3.0 has the shape and motion system tokens.

We also want to make it easier to use Material Design tokens, such as applying Material typescale, shape, and color to your own components.

Density and spacing tokens

Link to “Density and spacing tokens” #

Density allows components to take up less vertical space for larger displays. While we have some spacing tokens already, we need a comprehensive spacing system to fully support density across components.

Create TSX components

Link to “Create TSX components” #

TSX is a popular language extension for frameworks like React. We want to make it easier and more seamless to use Material Web Components in TSX.

Explore Material Design layouts

Link to “Explore Material Design layouts” #

Components are only part of the story to build fully expressive Material Design applications. We want to explore ways to support building applications that follow Material's layout patterns.

Follow accessibility best practices

Link to “Follow accessibility best practices” #

Completed in Q1 2024

Everyone should be able to access and enjoy the web. We want our components to help others build accessible experiences. The following screen readers are fully supported:

  • VoiceOver
  • Talkback
  • ChromeVox
  • JAWS
  • NVDA

Install Material Web 3.0

Your browser did not offer to install the docs as an app. Install them from the browser instead:

  • Chrome and Edge: open the browser menu and choose Install Material Web 3.0 (Chrome: Cast, save and share, Install page as app), or use the install icon in the address bar.
  • Safari on Mac: choose File, then Add to Dock.
  • Safari on iPhone and iPad: tap Share, then Add to Home Screen.
  • Firefox: Firefox on Android has Install in its menu. Firefox on desktop cannot install web apps; bookmark this page instead.
