FAB menu

A FAB menu opens from a FAB to show several related actions, and the FAB becomes its close button.

View as Markdown

Install with shadcn/ui: npx shadcn@latest add https://material-web.dev/3.0/r/md-fab-menu.json (setup)

Usage guidelines

Link to “Usage guidelines” #
  • Open it from a FAB. The menu appears where the FAB was, and not from an extended FAB or any other component.
  • Keep it related. A menu holds 2 to 6 closely related actions under one purpose, such as sharing.
  • Align to the trailing edge. The FAB and menu sit at the trailing edge of the window, mirrored in right-to-left languages.
  • Always label items. Every item needs a text label.

This component is new in M3 Expressive.

Anatomy

Link to “Anatomy” #

A FAB menu holds items and a FAB that toggles it. Both icons can be replaced.

Examples

Link to “Examples” #

Colors

Link to “Colors” #

Set color to primary (default), secondary or tertiary.

Size

Link to “Size” #

Set size to md or lg for a larger FAB.

Start alignment

Link to “Start alignment” #

Set align="start" to align the items to the start edge, as for a FAB at the leading side.

Open and events

Link to “Open and events” #

Set open to open the menu from code. The toggle event fires before it opens or closes and activate fires before an item closes it; cancel either to keep the menu as it is.

Accessibility

Link to “Accessibility” #
  • Name the menu with aria-label, such as "Message actions". It labels the toggle button.
  • The toggle button exposes whether the menu is expanded or collapsed.
  • Tab moves through the button and the items, and Enter or Space activates the focused one.
  • A menu over scrolling content shouldn't hide focused elements. Register it with setupScrollPadding() from appbar/scroll-padding.js.

API reference

Link to “API reference” #

<md-gb-fab-menu>

Link to “<md-gb-fab-menu>” #

A Material Design component.

Properties

Link to “Properties” #
Property Attribute Type Default
align
The alignment of the items. Defaults to the end, as the FAB.		 align FabMenuAlign FAB_MENU_ALIGNS.end
color
The color of the FAB, close button and items.		 color FabMenuColor FAB_MENU_COLORS.primary
open
Whether the menu is open.		 open boolean false
size
The size of the FAB. The close button is always the same size.		 size FabSize 'default'

Slots

Link to “Slots” #
Slot Description
default The menu's items, typically <md-gb-fab-menu-item>s.
close-icon The close button's icon. Defaults to a "close" icon.
icon The FAB's icon. Defaults to an "add" icon.

Events

Link to “Events” #
Event Description
activate
CustomEvent<FabMenuActivateDetail>		 Fired when an item is activated, before the menu closes. Cancel it to keep the menu open.
toggle
ToggleEvent		 Fired when the menu opens or closes from user interaction, before the change. Cancel it to keep the menu as it is.
