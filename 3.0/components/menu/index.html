Menus

Menus show a temporary set of actions or choices, opened from a button, a text field or a context.

View as Markdown

Install with shadcn/ui: npx shadcn@latest add https://material-web.dev/3.0/r/md-menu.json (setup)

Usage guidelines

Link to “Usage guidelines” #
  • Use it for temporary actions. A menu shows a short set of actions on demand. To show actions on screen at all times, use a toolbar.
  • Open it from many places. A menu can open from a button, an icon button, a split button or a text field, or as a context menu.
  • Organize long menus. Use groups with labels and dividers to separate related choices.
  • Choose a color. The standard color suits most menus; vibrant makes the selected items stand out.

Anatomy

Link to “Anatomy” #

A menu holds items, groups and dividers. An item holds a label and optional slots, including a submenu.

Examples

Link to “Examples” #

Opening a menu

Link to “Opening a menu” #

A menu is a popover. Point an md-gb-button (or md-gb-icon-button, or a native button) at it with popovertarget, or call showPopover() from script. The menu positions itself next to the button and closes on Escape, when focus leaves, or when an item is chosen.

Icons and supporting text

Link to “Icons and supporting text” #

Fill the leading, supporting-text, trailing-text and trailing slots to add detail to an item.

Groups

Link to “Groups” #

Wrap related items in an md-gb-menu-group. Set label for a heading, and checkable to single or multiple to make the items selectable like radio buttons or checkboxes. Use checked on the selected items.

Grouped layout

Link to “Grouped layout” #

Set layout="grouped" to show each group on its own surface with a gap between them, instead of one surface with dividers.

Vibrant color

Link to “Vibrant color” #

Set color="vibrant" to use the tertiary color roles instead of the surface-based standard style.

Submenus

Link to “Submenus” #

Put an md-gb-menu in an item's submenu slot. It opens beside the item on click, Enter, Space or the Right arrow key (Left in right-to-left layouts).

Context menu

Link to “Context menu” #

Set context-for to the id of an element to open the menu on a secondary click, the context menu key or a long press.

Density

Link to “Density” #

Set density from 0 (default) down to -3 to remove 4px of height per item for each step. Submenus inherit it. Keep it off by default and let people opt in.

Accessibility

Link to “Accessibility” #
  • The menu has role="menu", and items have role="menuitem", or menuitemradio and menuitemcheckbox in checkable groups.
  • On the button that opens the menu, Up and Down open it and focus the first item; Enter and Space open it natively.
  • In an open menu, Up and Down move between items (disabled items included), Home and End go to the first and last item, and typing a letter jumps to the next item that starts with it.
  • Escape and Tab close the menu and return focus to the button. Left (Right in right-to-left layouts) closes a submenu.
  • Give a menu that has no clear visible title an aria-label.

API reference

Link to “API reference” #

<md-gb-menu>

Link to “<md-gb-menu>” #

A Material Design component.

Properties

Link to “Properties” #
Property Attribute Type Default
color
The color style: standard (surface-based) or vibrant (tertiary).		 color MenuColor MENU_COLORS.standard
contextFor
The id of an element (in the same root) that opens this menu as a context menu on a secondary click, the context menu key or a long press (menus.md "Context menus ... usually open with a secondary click"; "Performs a specific action to trigger the menu, like right-click or press-and-hold").		 context-for string ''
density
The density, from 0 (default) to -3 (menus.md "Density": "On web only, density levels control the spacing between elements. Increasing density decreases the top and bottom padding"). Each step removes 4px from the items' height; submenus inherit it. Values are clamped to that range. Dense items are smaller than the 48px recommended target, so don't apply density by default; let people opt in (grids-spacing.md "Avoid applying component scaling by default").		 density Density
filterFor
The id of a text field (in the same root) the menu is attached to. As the person types in it, the menu opens (without taking focus) and shows only the items whose label contains the text, case-insensitively (menus.md "Filtering": "As someone types, the list of menu options filters to show relevant results"). The remaining items ease into their new position ("Menu items ease into their new position as the menu is filtered"), unless motion is reduced. Fires filter with the query.		 filter-for string ''
layout
The layout: standard items on one surface, or grouped md-gb-menu-groups on separate surfaces with gaps between them.		 layout MenuLayout 'standard'

Methods

Link to “Methods” #
Method Description
closeAll
() => void		 Closes this menu and every menu it is a submenu of.
filter
(query: string) => void		 Shows only the items whose label contains query, easing the others into their new position.
showAt
(x: number, y: number) => void		 Opens the menu at a point in the viewport (a context menu), keeping it inside the window: it opens below and after the point, and flips when there is no room.
