Button Group

A button group arranges related buttons and can manage their selection, density and overflow.

View as Markdown

Install with shadcn/ui: npx shadcn@latest add https://material-web.dev/3.0/r/md-button-group.json (setup)

Usage guidelines

Link to “Usage guidelines” #
  • Choose standard or connected. In a standard group, buttons respond to the one that is pressed; a connected group joins them into one control.
  • Keep buttons alike. Use the same size and shape for every button, and mix sizes only for hero moments.
  • Group related buttons. Mix colors and widths to emphasize what matters and to group related actions.
  • Let it adapt. On narrow screens, trailing buttons can collapse into an overflow menu.

This component is new in M3 Expressive.

Anatomy

Link to “Anatomy” #

A button group holds md-gb-button elements, each with an optional icon.

Examples

Link to “Examples” #

Connected

Link to “Connected” #

Set variant="connected" for buttons that sit together as a single control.

Selection

Link to “Selection” #

Set selection to single or multiple and give each button a value. Add required to keep one selected in a single-select group. A group fires input and change when selection changes.

Icons

Link to “Icons” #

Buttons in a group can be icon-only. Give each one an aria-label.

Density

Link to “Density” #

Set density from 0 (default) to -3 to make the buttons shorter. Touch targets stay 48px.

Overflow menu

Link to “Overflow menu” #

Add overflow-menu to collapse the buttons that don't fit into a menu at the trailing edge. Choosing a menu entry clicks the original button.

Accessibility

Link to “Accessibility” #
  • The group does not need a label of its own, but a name such as aria-label="Text alignment" helps when the buttons form a set.
  • Label each button as you would a button; icon-only buttons need aria-label.
  • Tab enters the group, Arrow keys move between buttons, and Enter or Space activates the focused button.

API reference

Link to “API reference” #

<md-gb-button-group>

Link to “<md-gb-button-group>” #

A Material Design button group.

Properties

Link to “Properties” #
Property Attribute Type Default
density
The density of the buttons inside, from 0 (default) to -3. Each step down removes 4px from the buttons' height (button-groups.md: "Button groups adapt to the height of the buttons inside, including when density is applied"); touch targets stay 48px. A button's own non-zero density wins. Values are clamped to that range.		 density Density
disabled
Whether the button group is disabled.		 disabled boolean false
overflowMenu
Whether the buttons at the trailing edge that do not fit collapse into a trailing overflow menu, and come back when the group has room again (button-groups.md, Adaptive design: "Buttons at the trailing edge of the button group can be customized to collapse into an overflow menu at smaller breakpoints, and become visible again at larger sizes."). The group is as wide as its container allows: give it a width, or put it in a narrower container, to make buttons overflow. Choosing a menu entry clicks the original button.		 overflow-menu boolean false
required
Whether selection is required in single-select mode.		 required boolean false
resizing
How the group and its buttons resize (button-groups.md, Resizing). fixed: every button keeps the width its own size and width give it. flexible: the group fills the width of its container and its buttons grow with it; an icon button does not stretch past its set width, and a button with resizing="fixed" keeps its width. A button with resizing="flexible" in a fixed group grows when the group is given more width. Unset: a connected group is flexible (it spans its surface), a standard group is fixed.		 resizing ButtonGroupResizing ""
selection
The selection mode.		 selection ButtonGroupSelection "none"
variant
The visual variant of the button group.		 variant ButtonGroupVariant "standard"
