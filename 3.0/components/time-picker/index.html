Time picker

Time pickers let people choose an hour and minute on a clock dial, or type them into fields.

View as Markdown

Install with shadcn/ui: npx shadcn@latest add https://material-web.dev/3.0/r/md-time-picker.json (setup)

Usage guidelines

Link to “Usage guidelines” #
  • Dial or input. The dial is quick for picking an approximate time, and typing is faster for an exact one. People can switch between them unless you hide the toggle.
  • Inline or modal. Show the picker inline in a form, or as a modal when it opens from a field or button.
  • Match the locale. The picker follows the 12 or 24 hour clock of its locale. Set hour-cycle to force one.

Anatomy

Link to “Anatomy” #

A time picker has a headline, the hour and minute selectors, an AM or PM toggle in 12 hour mode, a dial, and the actions.

Examples

Link to “Examples” #

Inline and modal

Link to “Inline and modal” #

Add modal to show the picker in a dialog with a scrim. Open it with show(). It fires change when a time is confirmed and cancel when it is dismissed.

Input mode

Link to “Input mode” #

Set mode="input" to start with hour and minute fields instead of the dial. Add hide-mode-toggle to remove the switch between the two.

Hour cycle

Link to “Hour cycle” #

Set hour-cycle to 12 or 24. The value is always a 24 hour HH:MM string.

Orientation

Link to “Orientation” #

The dial sits below the time selectors (vertical), except in short landscape windows, where it moves beside them (horizontal). Set orientation to choose one.

Density

Link to “Density” #

Set density from 0 (default) to -3 to make the picker more compact.

Accessibility

Link to “Accessibility” #
  • Input mode is an alternative to the dial, and every control has a label. Localize the labels with attributes such as select-hour-label, hour-label, cancel-label and confirm-label.
  • A modal picker is a <dialog>: focus moves into it and returns to the opener on close, and Escape cancels.
  • In the dial, the arrow keys change the selected hour or minute.

Events

Link to “Events” #
Event Description
cancel
Event		 Fired when picking is canceled (Cancel, Escape, scrim click). Cancelable for a modal picker; canceling keeps it open.
change
Event		 Fired when a new value is committed (OK, or the end of an interaction with hide-actions).
close
Event		 Fired when a modal picker closes.
input
Event		 Fired whenever the picked time changes (dial drag, key, typed digits, period). Read the pending time from pendingValue.
open
Event		 Fired when a modal picker opens.

Methods

Link to “Methods” #
Method Description
cancel
(reason?: string) => void		 Discards the pending time and fires cancel; a modal picker closes unless the event is canceled (canceling keeps the pending time). What the Cancel action does.
close
(reason?: string) => Promise<void>		 Closes a modal picker without committing. Fires a cancelable close event with detail.reason, then closed after the exit transition.
confirm
() => void		 Commits the pending time to value (firing change when it differs) and closes a modal picker. What the OK action does.
show
() => Promise<void>		 Opens a modal picker on the committed time, starting with the hours. Fires open.
toggleMode
() => void		 Switches between the dial and input modes.
