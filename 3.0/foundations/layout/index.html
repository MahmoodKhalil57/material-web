Layout

Layout adapts an app to the window with window size classes, a column grid, margins and panes.

View as Markdown

Layout adapts an app to the window. The window size class (see Adaptive layout) sets the layout tokens on :root:

  • --md-sys-layout-columns: 4 at compact, 8 at medium and expanded, 12 from large up.
  • --md-sys-layout-margin: 16px at compact, 24px above.
  • --md-sys-layout-spacer: the gutter between columns, 16px at compact, 24px above.

Window size classes and grid

Link to “Window size classes and grid” #

.md-layout-grid lays its children out on the column grid, with the margin as inline padding and the spacer as the gap.

Foldables

Link to “Foldables” #

On a foldable device, the fold's position and size are available as --md-sys-layout-fold-left and --md-sys-layout-fold-width (vertical fold) or --md-sys-layout-fold-top and --md-sys-layout-fold-height (horizontal fold). To react in code, observe the fold. The callback gets null when there is none.

Install Material Web 3.0

Your browser did not offer to install the docs as an app. Install them from the browser instead:

  • Chrome and Edge: open the browser menu and choose Install Material Web 3.0 (Chrome: Cast, save and share, Install page as app), or use the install icon in the address bar.
  • Safari on Mac: choose File, then Add to Dock.
  • Safari on iPhone and iPad: tap Share, then Add to Home Screen.
  • Firefox: Firefox on Android has Install in its menu. Firefox on desktop cannot install web apps; bookmark this page instead.
