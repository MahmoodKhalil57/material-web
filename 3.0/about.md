# About

Get started with Material Web 3.0 and find the project information: quick start, migration, support, roadmap and browser support.

Getting started and project information: how to install and use Material Web 3.0, how it follows the Material 3 spec, what is coming next, and where to get help.

- [Introduction](/material-web/3.0/about/intro/): Material web, also known as Material Web Components or MWC, is a library of web components that follows Google's Material Design guidelines.
- [Spec compliance](/material-web/3.0/about/compliance/): What the spec checks, ARIA and axe results, Baseline use and size budgets say about md-gb-* components.
- [Quick Start](/material-web/3.0/about/quick-start/): For fast prototyping, use a CDN such as esm.run to load @material/web without installing it.
- [Migration](/material-web/3.0/about/migration/): Version 3.0 renames most elements from md- to md-gb- and moves them to Material 3 Expressive.
- [Roadmap](/material-web/3.0/about/roadmap/): This roadmap describes current, future, and past goals for Material Web Components.
- [Support](/material-web/3.0/about/support/): Version 3.0 targets Baseline widely available: the web platform features it uses have worked in all major browsers for at least 30 months.
- [Bundle Sizes](/material-web/3.0/about/size/): Every md-gb- component is checked against a Brotli-compressed size budget for its JavaScript and CSS (the measured size plus 10% headroom), defined in scripts/size/gb-budgets.json.
- [Browser support](/material-web/3.0/about/browser-support/): Version 3.0 only uses web platform features that are Baseline widely available.
- [AI agents](/material-web/3.0/about/ai-agents/): labs/gb/skill/ is a Claude Code skill named md-gb.
- [Debugging](/material-web/3.0/about/debugging/): The shared plumbing of the components (motion waits, overflow measure passes, and scroll steps) can record performance marks.
- [Use with shadcn/ui](/material-web/3.0/about/shadcn/): Install the md-gb elements as React components with the shadcn CLI, themed by your shadcn variables.
