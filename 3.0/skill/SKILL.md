# md-gb: Material 3 Expressive web components

Generated by `scripts/m3/gen-agent-skill.mjs` from the component sources and `scripts/m3/CHECKLIST.md`. Do not edit by hand; run `npm run m3:update` or the script to refresh.

## How to use

1. Find the component below and open its reference file (`reference/<component>.md`) before writing markup. It lists every tag with attributes, properties, slots, events, CSS parts, custom properties and the usage rules the library follows.
2. Import only the elements you use, for example `import '@material/web/labs/gb/components/button/md-gb-button.js';`; `components/all.js` registers everything.
3. Use attributes for static configuration and properties for state set from code. Boolean attributes are present or absent: never write `selected="false"`.
4. Style with the documented CSS custom properties and parts. Colors, shapes, type and motion come from the M3 tokens (`--md-sys-*`); override tokens instead of hard-coding values.
5. Read `reference/app-owned.md` for what stays in the app: labels, layout placement, content, and decisions such as which variant to show at which window size.
6. Form-associated elements list `name`, `value` and `disabled` in their property table; use the native `input` and `change` events the events list names.
7. Every interactive control needs an accessible name: visible label text in the default slot or an `aria-label`. Icon-only controls always need `aria-label`.
