# prose

Elements: `md-gb-prose`.

## API

### `<md-gb-prose>`

A container that styles long-form text with the M3 type scale.

Source: `material-design-expressive/extras/prose/md-gb-prose.ts`  
Import: `import '@material/web/extras/prose/md-gb-prose.js';`

Slots

- default slot: The text: native elements such as `<h2>`, `<p>`, `<ul>`, `<a>`, `<pre>`, `<table>`, and components.

Methods

- `connectedCallback`: `() => void`
- `disconnectedCallback`: `() => void`
